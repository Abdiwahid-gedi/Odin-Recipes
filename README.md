# Odin-Recipes

This project is a simple recipe website built using only HTML.  
It is part of **The Odin Project** Foundations curriculum.

## Project Description

The website consists of a main index page that links to several individual recipe pages. Each recipe page includes a title, image, ingredients list, and step-by-step cooking instructions.

## Skills Demonstrated

By completing this project, I practiced:

- Writing semantic HTML
- Structuring a basic website
- Using headings, paragraphs, lists, links, and images
- Organizing files and folders in a project

## What I Learned

This project helped me better understand how HTML pages are structured and how multiple pages connect together in a website.
